    RNX CODE 게임 방법

    RNX CODE는 흔히 ‘다빈치 코드’로 알려진 보드게임의 규칙을 따릅니다. 상대가 숨긴 숫자 타일을 모두 맞혀 공개시키고, 내 타일은 끝까지 숨기는 추리 게임입니다. 마지막까지 숨긴 타일이 남은 사람이 이깁니다.

    타일과 정렬

    • 검정·흰색 타일이 0부터 11까지 한 장씩, 모두 24장입니다.
    • 누구나 자기 타일을 작은 수에서 큰 수 순서로 세워 둡니다. 같은 숫자면 검정이 왼쪽입니다.
    • 숫자는 숨겨도 색과 위치는 모두에게 보입니다. 이것이 추리의 단서입니다.

    차례 진행

    1. 더미에서 타일을 한 장 뽑습니다. (앱이 자동으로 뽑아 줍니다)
    2. 상대의 숨은 타일 하나를 고르고 숫자를 선언합니다.
    3. 맞히면 그 타일이 공개되고, 계속 추리할지 멈출지 고릅니다. 멈추면 뽑은 타일을 숨긴 채 내 줄에 넣습니다.
    4. 틀리면 뽑은 타일을 공개한 채 내 줄에 넣고 차례가 끝납니다.
    5. 더미가 비었는데 틀리면 내 타일 하나를 직접 골라 공개합니다.
    정렬 → 관찰 → 추리 → 숫자 선언 → 정답이면 계속 또는 멈춤 / 오답이면 내 타일 공개

    추리 요령

    • 양옆 타일 사이의 숫자만 가능합니다. 2와 7 사이의 흰 타일은 3~6 중 하나입니다.
    • 내가 가진 타일과 이미 공개된 타일은 후보에서 뺍니다.
    • 누군가 틀린 숫자는 타일 아래에 7처럼 남습니다. 그 숫자는 그 타일이 아닙니다.
    • 계속 공격할수록 이득이지만, 한 번 틀리면 뽑은 타일이 공개되어 불리해집니다.

    표시

    • 아래쪽 청록 선이 있는 타일은 공개된 타일입니다.
    • 내 타일 오른쪽 위의 작은 네모는 아직 숨겨져 있다는 뜻입니다.
